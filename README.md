# WebFlow CMS

A responsive web development and content management platform built with HTML5, SCSS, JavaScript ES6, and NPM.

## Requirements

**1. before running the project, install:**

- Node.js 16+
- NPM 8+
- Git
- VS Code
- Live Server extension

**2. Check the installation:**

```bash
node -v
npm -v
git --version

**3. Install dependencies**

Run:

npm install

This installs the required packages from package.json.

**4. Start Sass**

Run:

npm run sass

This compiles:

scss/main.scss → css/main.css

Keep this terminal running while working on the project.

**5. Start the website**

In VS Code:

Open index.html
Right-click the file
Select Open with Live Server
The project will open in your browser.
